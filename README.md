# TriGardening 🌱

A modern gardening service website built with Next.js 16  
Live Demo: https://trigardening.netlify.app

## Features
- Fast & optimized Next.js UI
- Modern layout and responsive design
- Gardening services showcase
- Contact section

## Tech Stack
- Next.js 16 (App Router)
- Tailwind CSS
- Netlify Deployment

## Run Locally
npm install  
npm run dev
